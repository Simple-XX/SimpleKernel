### 超越 C++ 的设计改进

#### 1. 函数项分发替代虚函数（零成本中断处理）

C++ 使用 `etl::delegate` + 虚函数分发中断，每次中断需要间接调用。Rust 使用函数指针数组可以实现零虚表开销：

```rust
/// 中断处理函数类型 —— 不需要 trait 对象
type InterruptHandler = fn(irq: IrqNumber, ctx: &mut TrapContext);

/// 中断分发表 —— 直接索引，零间接成本
static INTERRUPT_HANDLERS: SpinLock<[Option<InterruptHandler>; MAX_IRQ_COUNT]> =
    SpinLock::new([None; MAX_IRQ_COUNT]);

/// 注册处理函数
pub fn register_handler(irq: IrqNumber, handler: InterruptHandler) -> KResult<()> {
    let mut table = INTERRUPT_HANDLERS.lock();
    table[irq.as_usize()] = Some(handler);
    Ok(())
}
```

对比 C++ 的 `etl::delegate<void(uint64_t, TrapContext*)>` + 虚分发，此方案零成本且类型安全。

#### 2. Newtype 中断号（消除与普通整数的混用）

C++ 中中断号是裸 `uint64_t`，容易与其他数字混用：

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub struct IrqNumber(u32);

impl IrqNumber {
    pub const fn new(n: u32) -> Option<Self> {
        if n < MAX_IRQ_COUNT as u32 { Some(Self(n)) } else { None }
    }
    pub const fn as_usize(self) -> usize { self.0 as usize }
}
```

#### 3. 类型安全的系统调用分发（替代 switch + reinterpret_cast）

C++ `syscall.cpp` 是一个巨大的 switch 语句，参数通过 `reinterpret_cast` 从 `uint64_t` 数组中提取。Rust 可以用 enum + 宏实现类型安全分发：

```rust
/// 系统调用号 —— 类型安全
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(u64)]
pub enum SyscallNumber {
    Write = 64,
    Exit = 93,
    Yield = 124,
    Clone = 220,
    // ...
}

/// 系统调用参数 —— 每个 syscall 有自己的类型化参数
pub enum SyscallArgs {
    Write { fd: i32, buf: *const u8, len: usize },
    Exit { code: i32 },
    Clone { flags: CloneFlags, stack: VirtAddr },
    // ...
}

/// 从 TrapContext 提取并类型化参数 —— 消除 reinterpret_cast
fn parse_syscall(ctx: &TrapContext) -> KResult<SyscallArgs> {
    let nr = SyscallNumber::try_from(ctx.syscall_number())?;
    match nr {
        SyscallNumber::Write => Ok(SyscallArgs::Write {
            fd: ctx.arg(0) as i32,
            buf: ctx.arg(1) as *const u8,
            len: ctx.arg(2) as usize,
        }),
        // ... 编译器保证处理所有 syscall
    }
}
```

#### 4. `offset_of!` 编译期验证（已稳定）

原计划步骤 7b 中的 `core::mem::offset_of!` 自 Rust 1.77 起已稳定，无需 nightly 特性。建议扩展验证范围：

```rust
// 验证 TrapContext 布局与 interrupt.S 中的偏移一致
const _: () = {
    assert!(core::mem::size_of::<TrapContext>() == TRAP_CONTEXT_SIZE);
    assert!(core::mem::offset_of!(TrapContext, ra) == 0);
    assert!(core::mem::offset_of!(TrapContext, sp) == 8);
    // ... 每个字段都验证
};

// 同时验证 CalleeSavedContext（用于 switch.S）
const _: () = {
    assert!(core::mem::size_of::<CalleeSavedContext>() == CALLEE_SAVED_SIZE);
    // ...
};
```

#### 5. TickObserver 用回调数组替代 trait 对象

C++ 使用 `etl::observer` 模式。Rust 中对于固定集合的观察者，直接用函数指针数组更高效：

```rust
type TickCallback = fn(tick: u64);

/// 最多 8 个 tick 观察者 —— 零分配
static TICK_OBSERVERS: SpinLock<heapless::Vec<TickCallback, 8>> =
    SpinLock::new(heapless::Vec::new());

pub fn register_tick_observer(cb: TickCallback) -> KResult<()> {
    TICK_OBSERVERS.lock().push(cb).map_err(|_| ErrorCode::TickObserversFull)
}
```
