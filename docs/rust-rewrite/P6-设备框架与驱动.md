## Rust 能力审阅补充（2026-03-25）

> 以下是基于对 C++ `device_manager.hpp`、`driver_registry.hpp`、`virtio_driver.hpp`、`pl011/*.hpp`、`ns16550a/*.hpp` 的审查。

### 超越 C++ 的设计改进

#### 1. MMIO 安全抽象（零成本 Volatile 包装）

C++ 中 MMIO 访问使用裸 `volatile` 指针，没有类型安全。Rust 可以构建零成本抽象，编译器保证只能通过 volatile 操作访问：

```rust
/// MMIO 寄存器 —— 只能通过 volatile 操作访问，零运行时开销
#[repr(transparent)]
pub struct ReadOnly<T: Copy>(UnsafeCell<T>);
#[repr(transparent)]
pub struct WriteOnly<T: Copy>(UnsafeCell<T>);
#[repr(transparent)]
pub struct ReadWrite<T: Copy>(UnsafeCell<T>);

impl<T: Copy> ReadOnly<T> {
    pub fn read(&self) -> T {
        unsafe { core::ptr::read_volatile(self.0.get()) }
    }
    // 没有 write 方法 —— 编译器阻止对只读寄存器的写入
}

impl<T: Copy> WriteOnly<T> {
    pub fn write(&self, val: T) {
        unsafe { core::ptr::write_volatile(self.0.get(), val) }
    }
    // 没有 read 方法 —— 编译器阻止对只写寄存器的读取
}

/// PL011 寄存器块 —— 编译器验证偏移量，区分读/写/读写
#[repr(C)]
pub struct Pl011Regs {
    pub dr: ReadWrite<u32>,       // 0x000 数据寄存器
    pub rsr: ReadOnly<u32>,       // 0x004 接收状态
    _reserved0: [u8; 16],
    pub fr: ReadOnly<u32>,        // 0x018 标志寄存器（只读！C++ 中没有强制）
    // ...
}
```

C++ 的 `mmio_accessor.hpp` 不区分只读/只写/读写，Rust 在类型层面保证。

#### 2. Driver trait 用关联类型（替代 void* 私有数据）

C++ 的设备框架使用 `void*` 存储驱动私有数据。Rust 用关联类型在编译期绑定：

```rust
pub trait Driver: Send + Sync {
    /// 驱动私有数据类型 —— 编译期绑定，无需 void*
    type PrivateData: Send + Sync;

    /// 兼容性字符串（FDT compatible）
    fn compatible() -> &'static [&'static str];

    /// 探测设备 —— 成功返回私有数据
    fn probe(node: &FdtNode) -> KResult<Self::PrivateData>;

    /// 移除设备
    fn remove(data: Self::PrivateData) -> KResult<()>;
}
```

#### 3. 设备拥有其缓冲区（所有权耦合）

C++ VirtIO 驱动中，DMA 缓冲区和设备是分离的数组（`std::array<std::optional<VirtioBlk>, N>` + 独立的缓冲区数组）。Rust 的所有权模型天然耦合设备和其资源：

```rust
/// VirtIO 块设备 —— 拥有自己的 DMA 缓冲区
pub struct VirtioBlkDevice {
    transport: VirtioMmioTransport,
    queue: VirtQueue,
    /// DMA 缓冲区与设备绑定 —— 设备 Drop 时自动释放
    dma_buffer: IoBuffer,
    slot_buffer: IoBuffer,
}

// 设备 Drop 时，所有资源自动释放
// C++ 需要手动确保缓冲区在设备之后释放
```

#### 4. 设备枚举用 Iterator（替代手动遍历）

C++ 的 FDT 枚举需要手动递归遍历节点。Rust 可以利用 Iterator trait：

```rust
/// FDT 节点迭代器 —— 惰性求值，可以用 filter/map/collect
pub fn enumerate_devices(fdt: &KernelFdt) -> impl Iterator<Item = FdtDeviceInfo> + '_ {
    fdt.all_nodes()
        .filter(|node| node.compatible().is_some())
        .map(|node| FdtDeviceInfo {
            name: node.name,
            compatible: node.compatible().unwrap(),
            reg: node.reg(),
            interrupts: node.interrupts(),
        })
}

// 使用时
for device in enumerate_devices(&fdt) {
    if let Some(driver) = registry.find_driver(&device.compatible) {
        driver.probe(&device)?;
    }
}
```

#### 5. VirtIO 队列用 const generics（编译期容量检查）

C++ VirtIO 队列容量在运行时设置。Rust 可以用 const generics 在编译期固定：

```rust
/// VirtQueue 容量在编译期确定
pub struct VirtQueue<const SIZE: usize> {
    desc: [VirtqDesc; SIZE],
    avail: VirtqAvail<SIZE>,
    used: VirtqUsed<SIZE>,
    free_head: u16,
    last_used_idx: u16,
}

// 编译期保证队列大小是 2 的幂
const _: () = assert!(SIZE.is_power_of_two());
```
