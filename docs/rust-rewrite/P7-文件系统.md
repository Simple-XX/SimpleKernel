## 设计细节

### FatFS 适配层
FatFS 适配需要实现 `fatfs` crate 的 `ReadWriteSeek` trait，桥接 VirtIO 块设备：

```rust
/// VirtIO 块设备到 fatfs I/O 的适配器
struct VirtioBlockAdapter {
    device: &'static VirtioBlkDevice,
    position: u64,
}

impl fatfs::IoBase for VirtioBlockAdapter {
    type Error = KernelError;
}

impl fatfs::Read for VirtioBlockAdapter { /* 调用 device.read_block() */ }
impl fatfs::Write for VirtioBlockAdapter { /* 调用 device.write_block() */ }
impl fatfs::Seek for VirtioBlockAdapter { /* 更新 position */ }
```

### 文件描述符表
- 每个任务持有独立的 FD 表（`Vec<Option<FileDescriptor>>`）
- FD 0/1/2 预留给 stdin/stdout/stderr
- 最大 FD 数量由 `config.rs` 中的 `MAX_FD_PER_TASK` 常量控制（建议默认 256）
- `FileDescriptor` 包含：VFS 文件引用、当前偏移量、打开标志（读/写/追加）

## 退出标准
1. RamFS: create/read/write/delete/mkdir/rmdir/readdir 全部工作
2. VFS: 挂载 RamFS 到 `/`，路径查找正确
3. 文件描述符: open/close/read/write/seek 通过 FD 表工作
4. FatFS: 从 VirtIO 块设备挂载
5. FileSystemInit() 无错误完成
6. 完整启动序列在 QEMU 中运行到 "fully booted"
