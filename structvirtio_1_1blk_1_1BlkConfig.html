Detailed Description

块设备配置空间布局

See also
virtio-v1.2#5.2.4 Device configuration layout

设备配置空间包含设备的静态配置信息，如容量、最大段大小、 几何信息、拓扑信息等。驱动程序通过传输层读取这些信息。

Note
配置空间使用小端格式
多字节字段需要使用 generation counter 机制确保读取一致性
