Detailed Description

DMA 可访问内存区域的非拥有描述符

将虚拟地址、物理（总线）地址和大小封装为单一值类型。 不拥有内存所有权——生命周期由分配器（如 IoBuffer）管理。

Note
类 POD 类型，可平凡拷贝，可安全按值或 const 引用传递。
